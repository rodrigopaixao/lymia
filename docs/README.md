Primeiro entenda a arquitetura geral. Depois abra o Node-RED e acompanhe cada no usando o documento `02-explicacao-dos-nos.md`. Por fim, leia o documento de funcoes com o `flows.json` aberto ao lado.

Para apresentar ao professor, use principalmente:

- `01-visao-geral.md`
- `02-explicacao-dos-nos.md`
- `05-validacoes-e-erros.md`
- `06-roteiro-apresentacao.md`
